# Esra Yaman · Kişisel Portföy

[Canlı siteyi aç](https://esrayamann.github.io/webodev1/)

Esra Yaman'ın seçili yazılım projelerini, teknik odağını ve GitHub çalışmalarını bir araya getiren erişilebilir, responsive ve bağımlılıksız statik portföy sitesi.

## Öne çıkanlar

- Mobil öncelikli ve tüm ekran boyutlarına uyumlu arayüz
- Anlamsal HTML, atlama bağlantısı ve görünür odak durumlarıyla erişilebilir yapı
- Açıklayıcı SEO ve Open Graph meta etiketleri
- Harici JavaScript ya da derleme adımı olmadan hızlı açılış
- NetInspector, MyWeTransferGo ve Arıza projelerine doğrudan bağlantılar

## Yerelde görüntüleme

Bu proje saf HTML ve CSS kullanır. Dosyayı doğrudan tarayıcıda açabilir veya küçük bir yerel sunucu çalıştırabilirsin:

```bash
python3 -m http.server 8000
```

Ardından [http://localhost:8000](http://localhost:8000) adresini aç.

## Dosya yapısı

```text
.
├── index.html     # Sayfa içeriği ve anlamlı yapı
├── styles.css     # Responsive tasarım sistemi
├── fotograf/      # Eski proje görselleri
└── video/         # Eski proje videoları
```
